# Git Sandbox

> Учебный черновик для первых коммитов и экспериментов с Python и Git.

**Стек:** Python · Git

## Назначение

Песочница для первых коммитов и пробных команд Python. Основной файл — `main.py`.

Текущий скрипт содержит обращение к неопределённому имени `dsa` и завершается с `NameError`. Репозиторий хранится как учебный черновик.
